# Netflix Content Analysis Dashboard

An interactive Power BI dashboard analyzing Netflix's global content distribution, content ratings, top genre, and monthly content addition.

## 📌 Project Overview

This dashboard provides a high-level executive view of Netflix's catalog. Designed with custom dark-modern aesthetics 
following Netflix's brand guideline, it enables stakeholder to explore global library dynamics, content classification distributions, and peak content addition periods.

## 📊 Key Insights & Features
|**Key Feature**|**Type**|**Core Insight**|
|:---|:---|:---|
|KPI Summary Cards|Executive Metric|Catalog size stands at 5,408 total titles, dominated by 3,767 movies vs 1,641 TV shows across 71 countries|
|Global Content Distribution| Geographic Map|Visualizes country-level catalog density, highlighing key regional markets and geographic reach.|
|Monthly Trend of Netflix Content|Area Chart|Tracks content additions across the calendar year, showcasing the peak releases in October (**597 titles**) and November(**565 titles**) with a annual low in February (**363 titles**) and June (**360 titles**).
|Count of Rating|Horizontal Bar|Demonstrates a heavy catalog focus on mature audiences, led overwhelming by **TV-MA** and **TV-14** rating categories.|
|Top Genres|Horizontal Bar|Identifies primary content pillars, with **Stand-Up Comedy** holding the top volume spot, followed by **TV Comedies** and **TV Dramas**.
|Interactive Slicers| Control Panel|Enable dynamic cross-filtering of all report visuals simultaneously by **Year**,**Type**, and **Country**.

## 🛠️ Data & Tech Stack
- **Business Intelligent Tool:** Microsoft Power BI Desktop.
- **Data Modeling & Analytics:** DAX(Data Analysis Expressions) for customdynamic time-intelligence measures and selective data label highlights.
- **Styling & UI/UX:** Netflix Brand Theme(```#E50914``` primary red, custom dark theme ```#141414```,custom gradient area chart fills)
